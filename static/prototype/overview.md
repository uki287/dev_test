## 后台管理系统原型（prototype/admin.html）

### 技术栈与架构
- 单文件 HTML（AntD 5.x 视觉：主色 `#1677FF`、深色菜单 `#001529`、内容区 `#F5F5F5`），Tailwind CDN + 原生 JS，无构建步骤。
- **共享数据层**：`localStorage` 键 `tp_smart_home_data` + `BroadcastChannel` `tp_smart_home_sync`，后台写入 → 前台（index.html）即时生效、双窗口实时同步。
- `DEFAULT_STORE` 深拷贝初始化；`loadStore()` / `saveStore(action,item)`（含自动审计日志 `recordLog`）；`refreshAll()` 安全刷新（各 render 独立 try/catch）。
- hash 路由 `ROUTES` / `CRUMB` / `NAV_GROUP`，15 个视图，含白屏兜底。

### 权限与登录安全（PRD §6.2）
- 默认账号 `admin` / 密码 `123456`。
- **L-01** 图形验证码；**L-03** 连续失败 5 次锁定 15 分钟（`tp_admin_login_state`）；账号停用拦截。
- **L-04** 首次登录 `needPwdChange` 强制改密后再进入后台。

### 已实现真实功能（对照 PRD §6）
- **轮播图管理 §6.4.1**：启停 / 新增编辑 Modal / 图片上传（dataURL 覆盖默认渐变）/ **起止时间** `startDate-endDate` + 列表未开始/已过期标记 / 启用数 0 阻止删除。
- **系列管理 §6.4.2**：真实 CRUD（`renderSeries` / 上移下移 `moveSeries` / 删除同步清空产品 `seriesId` / 筛选同步 `syncSeriesFilter`）。
- **产品管理 §6.4.2**：信息 Tab（系列/规格/属性/搭配/上下架/首页推荐）+ **内容 Tab**（`switchProductTab` 详情图多图上传 `addDetailImg` + 富文本 `#pContent`），保存写回 `STORE.products`。
- **新闻 / 招聘 §6.4.3/§6.4.4**：发布/下线/置顶、**作者与浏览量编辑**、复制、删；招聘邮箱投递（薪资说明 `salaryDesc`）。
- **关于管理 §6.4.5**：8 个 tab（含「首页品牌介绍」）；公司简介 / 品牌介绍**图片上传**（实拍图 → `company.image`、品牌视觉图 → `brand.image`）；时间轴增删行；**资质荣誉** `certEditor` 行级 CRUD 写入 `STORE.about.certs`。
- **预约管理 §6.5**：手机号脱敏、详情 Drawer、状态流转+处理备注、复选 **批量状态变更**、**Excel 导出**（无第三方库：`crc32`+`buildXLSX` ZIP stored）。
- **留言管理 §6.6**：同上批量 + 导出。
- **管理员 / 角色 / 操作日志 §6.7**：管理员增改/启停/删除/重置密码 `renderUsers`；RBAC 角色树 `renderRoles`；`renderLogs` 操作人/模块/日期筛选，所有写操作经 `saveStore` 自动留痕。
- **数据统计 §6.8**：工作台 7 天预约/留言 SVG 折线 `#dashboardApptLine/#dashboardMsgLine`；统计页预约环形 `#apptPieSegs` + 留言类型条形 `#msgTypeBars`，均由 `STORE` 实时计算。
- **系统设置 §6.9**：网站名/ICP/版权/联系方式/轮播间隔 + **Logo 上传**（`setLogoInput` → `settings.logo`，前台导航/页脚同步）+ **页脚链接** `footerLinksEditor` 动态增删行保存。

### 验证
- 两个文件业务脚本 `node --check` 均 **SYNTAX_OK**；`vm` + DOM 桩冒烟 **25/25 通过**：前后台顶层零异常；产品详情图组/价格/介绍、灯箱图片源、新闻作者/封面/置顶排序、招聘薪资、页脚站名/Logo/快捷链接/产品分类、首页品牌区、品牌介绍页、关于AI 实拍图/资质墙、isRecommend 精选映射、`normImageBg` 单引号转换、`loadStore` 兼容迁移（补 logo/homeIntro）全部验证通过。
- 临时验证脚本已清理，`prototype/` 仅留 `admin.html` / `index.html` / `overview.md`。

### 使用方式
1. 浏览器打开 `admin.html` → **无需登录，直接进入工作台**（演示模式已禁用登录；如需恢复，见 `router()` 内注释：显示 `#view-login` 并加会话校验）。
2. 在任意模块增改删内容并保存 → 顶栏「预览前台」或前台导航「管理后台」/ 页脚「后台管理」/ 悬浮按钮打开 `index.html`，即可看到改动即时生效。
3. 同时打开前后台两个窗口时，`BroadcastChannel` 实时同步，无需刷新。

### 图片持久化修复（v2.5.2 增强）
- 上传图片统一经 `normImageBg()` 规范为 **单引号 `url('data:...')`** 存储，修复此前 dataURL 双引号写入内联 `style="background:..."` 时属性引号冲突导致「封面图不显示 / 看似未持久化」的问题；产品/新闻/系列封面、Logo、公司实拍图、品牌视觉图、资质证书图均统一生效。
- `DEFAULT_STORE` 扩充 `settings.logo` 与 `about.homeIntro`；`loadStore()` 对旧 localStorage 数据自动兼容迁移（缺字段补默认值），无需清缓存。

### 登录入口（前台 → 后台）
- PC 导航右侧「管理后台」、移动端抽屉「管理后台登录」、页脚「后台管理」、右侧悬浮按钮，均新窗口打开 `admin.html`（演示模式直进后台，无需登录）。
- 后台头像下拉提供「预览前台」快捷入口，前后台双向可达。
