> **版本**：V1.0（草稿，待评审）
> **编写日期**：2026-08-18
> **依据文档**：`phototype/docs/企业家居官网PRD.md`（PRD V2.5.2）、`phototype/prototype/index.html`（前台高保真原型）、`phototype/prototype/admin.html`（后台高保真原型）
> **文档定位**：连接 PRD 需求与原型落地的「设计语言总纲」，供前端/后端开发、UI 设计、测试与评审共同遵循。

## 第 1 章 文档说明与范围

### 1.1 目的
本规范将 PRD 中的功能需求与两份高保真原型已落地的视觉、交互细节，沉淀为一套可复用的设计语言，解决三类常见问题：
- 设计与开发之间对「颜色、字号、间距、圆角」各写各的，缺乏统一 token；
- 原型中的交互细节（下拉单例、轮播主题联动、水平时间轴、表单隐私提示等）未被文档化，重构时丢失；
- 后台 Ant Design 风格组件与前台定制风格缺少统一约束，易产生视觉割裂。

### 1.2 适用范围
| 系统 | 范围 |
|------|------|
| 前台（官网） | 首页、产品、新闻、招聘、关于、联系我们 等全部访客可见页面 |
| 后台（管理端） | 登录、工作台、内容管理、预约/留言、系统管理、数据统计、系统设置 |
| 不涉及 | 服务端接口契约、数据库设计、部署架构（见 PRD 与研发文档） |

### 1.3 权威来源约定（重要）
为避免冲突，三方资料的优先级约定如下：
1. **需求权威 = PRD**：功能边界、字段、业务逻辑以 PRD 为准。
2. **视觉/交互落地权威 = 高保真原型**：本规范中的颜色、字体、组件样式、交互参数，以 `index.html` / `admin.html` 中已实现的代码为准（已逐行核对）。
3. **交叉参考 = ui-ux-pro-max CLI**：CLI 输出的「Liquid Glass / 暗色科技风」设计系统建议，**不采纳**为本项目的统一风格（与项目锁定的「暖墨黑 + 暖金 + 米白」高端简约调性冲突），仅用于提取可复用的通用最佳实践（无障碍、动效、性能），已在 §8–§10 中标注吸收点。

### 1.4 标注约定
- **【待确认】**：PRD 或原型中留空 / 占位，需企业决策后回填，**本文档不臆造内容**。
- **【原型已落地】**：原型中已实现，本文档仅做提炼与固化。
- **【建议】**：原型未覆盖或需强化，由本规范提出的设计建议。

### 1.5 阅读对象
- 设计师：第 2、3 章（原则与 token）必读；
- 前端开发：第 3–10 章；
- 后端开发（管理端）：第 3、5、9、10 章；
- 测试/评审：第 10、11 章走查清单。

## 第 2 章 设计目标与原则

### 2.1 品牌调性
PRD 锁定的风格关键词为 **「高端大气简约」**。结合原型落地，进一步定义为：

> **克制的奢华（Warm Minimalism）** —— 以大面积留白与墨黑底色承载「高端」，以低饱和暖金作为唯一的奢华点缀色，避免高饱和与花哨渐变带来的廉价感。

### 2.2 五条设计原则
1. **内容优先**：导航、按钮、装饰永远服务于内容；首页首屏用产品与品牌叙事说话，而非堆砌功能入口。
2. **一致即信任**：同一语义用同一组件、同一颜色（如「主操作」永远是暖金 `gold`；后台「主操作」用 `primary`）。
3. **可访问性内建**：从第一版就满足 WCAG 2.1 AA（对比度、焦点、触控目标），不事后补丁。
4. **性能即体验**：首屏骨架屏、图片懒加载、动效仅用 transform/opacity，保证低端机也能流畅。
5. **移动端不降级**：移动端不是「简化版」，是同一信息架构的重新排列（抽屉导航、栅格重排）。

### 2.3 设计语言速览
| 维度 | 取值 |
|------|------|
| 主色 | 暖金 `#B98A2F`（克制的奢华点缀） |
| 底色 | 墨黑 `#1C1814` / 米白 `#FAF8F4` |
| 标题字体 | Playfair Display + Noto Serif SC（衬线，气质感） |
| 正文字体 | Inter + PingFang SC（无衬线，可读性） |
| 圆角 | 大卡 16px / 按钮 8px / 标签 6px |
| 栅格 | 8pt 基准（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64） |

## 第 3 章 设计系统（Design Tokens）

> 本章所有数值均来自原型 `tailwind.config` 与 CSS，可直接作为 CSS 变量 / Tailwind theme 落地。

### 3.1 色彩系统

#### 3.1.1 前台（官网）色板
| Token | 色值 | 用途 |
|-------|------|------|
| `ink` | `#1C1814` | 主文字、导航底色、首屏深色背景 |
| `ink.light` | `#2A241D` | 次级深色块、卡片叠层 |
| `ink.soft` | `#3A3228` | 弱化文字、深色分隔 |
| `ink.deep` | `#12100C` | 最深底色、footer |
| `gold` | `#B98A2F` | **主强调色**：链接下划线、按钮、激活态、年份标记 |
| `gold.light` | `#D6B36A` | hover、高光、渐变端点 |
| `gold.soft` | `#EFE3C2` | 浅金底、标签底 |
| `gold.dark` | `#8F6A1E` | 深金（按压态/描边） |
| `cream` | `#FAF8F4` | 浅色页面底色、卡片底 |
| `cream.dark` | `#F3EFE7` | 浅色区块次级底 |
| `line` | `#E6DFD2` | 浅色模式分隔线、边框 |
| `line.dark` | `#3A342B` | 深色模式分隔线 |

**对比度安全组合**（满足 4.5:1）：
- 深底 `ink` 上放 `gold.light` 文字/图标 ✅
- 浅底 `cream` 上放 `ink` 文字 ✅
- 浅底 `cream` 上放 `gold` 文字 ⚠️ 需加粗或改用 `gold.dark`
- 深底 `ink` 上放 `gold`（#B98A2F）正文 ❌ 对比度不足，仅用于大字/图标

#### 3.1.2 后台（管理端）色板
| Token | 色值 | 用途 |
|-------|------|------|
| `primary` | `#B98A2F` | 主按钮、激活菜单文字、关键数据 |
| `primary.hover` | `#D6B36A` | 主按钮 hover |
| `primary.light` | `#EFE3C2` | 浅金底（选中行/标签） |
| `primary.dark` | `#8F6A1E` | 深金描边 |
| `layout` | `#FAF8F4` | 后台整体页面底色 |
| `menu` | `#000000` | 侧边栏底色（纯黑） |
| `menu.hover` | `#B98A2F` | 侧边栏 hover/激活（黑底金字） |
| `antd` | `#D9D9D9` | Ant Design 默认边框灰（表格/分隔） |

> 后台沿用 **Ant Design 5.x** 视觉语言（白底卡片、灰色边框、蓝色/绿/橙/红/灰/紫/金 状态标签），仅将品牌主色替换为暖金 `primary`，侧栏保持纯黑以呼应前台墨黑气质。

### 3.2 字体系统
| 角色 | 字体栈 | 用途 |
|------|--------|------|
| Display（标题） | `"Playfair Display", "Noto Serif SC", "Songti SC", SimSun, serif` | 前台大标题、品牌字、时间轴年份 |
| Body（正文） | `Inter, "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif` | 前台与后台全部正文、按钮、表单 |
| 后台标题 | Inter（Medium 500/600） | 后台页面标题、卡片标题（不用衬线，保持工具感） |

**加载策略**：Google Fonts 以 `display=swap` 引入；中文回退至系统字体（PingFang SC / 微软雅黑），避免 FOUT 抖动。

### 3.3 字号层级（Type Scale）
| 名称 | 前台(px) | 后台(px) | 字重 | 说明 |
|------|----------|----------|------|------|
| Display XL | 48–64 | — | 600 | 首屏主标题（Playfair） |
| H1 | 36 | 20 | 600 | 页面标题 |
| H2 | 28 | 16 | 600 | 区块标题 |
| H3 | 20 | 14 | 600 | 卡片标题 |
| Body | 16 | 14 | 400 | 正文 |
| Small | 14 | 12 | 400 | 辅助说明 |
| Caption | 12 | 12 | 400 | 标签、时间戳 |

> 后台整体字号比前台小一号（管理密度优先）；前台强调标题的「气质感」。

### 3.4 间距与栅格（8pt Grid）
基准单位 8px，允许 4px 微调。常用间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 页面主内容最大宽度：**1200px**（居中，左右留白随屏自适应）。
- 卡片内边距：24px；卡片间距：24px（移动端 16px）。
- 栅格列数：桌面 12 列；平板 8 列；移动 4 列（或单列堆叠）。

### 3.5 圆角（Radii）
| 元素 | 圆角 |
|------|------|
| 大卡片 / 图片容器 | 16px |
| 按钮 / 输入框 | 8px |
| 标签 / 小药丸 | 6px |
| 头像 | 50%（圆形） |
| 弹窗(后台 Modal) | 8px |

### 3.6 阴影（Shadows）
| Token | 值 | 用途 |
|-------|----|------|
| `shadow-gold` | `0 12px 32px -8px rgba(185,138,47,.35)` | 金强调元素的悬浮投影（按钮/卡片 hover） |
| `shadow-card` | 轻量 `0 2px 8px rgba(0,0,0,.06)` | 浅色卡片默认投影 |
| `shadow-drawer` | `0 8px 24px rgba(0,0,0,.18)` | 移动抽屉/后台抽屉 |

### 3.7 图标规范
- 线性图标为主，描边 1.5px，圆角端点；
- 默认尺寸 20px（移动端触控区放大到 44×44 点击热区）；
- 图标颜色跟随文字色，激活态切 `gold`；
- 统一图标库建议：【待确认】（如 Phosphor / Lucide，需企业选定授权）。

### 3.8 层级（Z-index）
| 层级 | 值 | 元素 |
|------|----|------|
| 遮罩 | 40 | 移动抽屉 mask、灯箱遮罩 |
| 抽屉/弹窗 | 50 | 后台 Modal/Drawer、图片灯箱 |
| 导航 | 30 | 前台 fixed 导航 |
| Toast | 60 | 轻提示（最顶层） |

## 第 4 章 前台信息架构与页面设计规范

### 4.1 信息架构（IA）
```
/                      首页
/products              产品信息（列表，支持系列筛选）
/products/content      产品内容（系列介绍/解决方案）
/products/:id          产品详情
/news                  新闻动态（列表，行业/产品分类）
/news/:id              新闻详情
/jobs                  招聘（列表，社会/校园分类）
/jobs/:id              职位详情（邮箱投递）
/about/company         关于·品牌介绍
/about/timeline        关于·发展历程（水平时间轴）
/about/brand           关于·品牌历程
/about/ai              关于·【待确认：AI 命名】     ← PRD 有「关于AI」，原型未单独实现，见 §11
/about/appointment     关于·在线预约（预约表单）
/contact               联系我们（信息+地图+留言）
```

> **PRD ↔ 原型差异提示**：PRD §5.1 列出关于页 5 个子页（关于AI / 发展历程 / 品牌历程 / 品牌介绍 / 在线预约）；高保真原型落地了「品牌介绍 / 发展历程 / 品牌历程 / 在线预约」四个 view，**「关于AI」未实现且命名待确认**。后台「关于」管理有 8 个 tab，可承载其余内容。

### 4.2 全局框架
- **导航栏**：`fixed top-0`，默认透明（首屏压图），滚动后变 `bg-ink/95` 实底（监听 scroll）。
- **导航项**：hover/active 显示金色下划线（`.nav-link::after`，0→100% 宽度，250ms）。
- **下拉菜单（单例）**：同一时间仅一个下拉展开（G-02 约束），点击其他项或外部自动收起。
- **移动抽屉**：`#drawer` 默认 `translateX(-100%)`，打开滑入；`#mask` 半透明遮罩，点击关闭。
- **视图切换**：各 view 以 `fadeUp`（透明度+位移）进场，避免生硬显隐。

### 4.3 首页（view-home）【原型已落地】
| 区块 | 内容 | 交互 |
|------|------|------|
| Banner 轮播 | 3 张：全屋智能 / 智能照明 / 智能安防 | 自动播放（间隔取自后台 `sliderInterval`，默认 4s），圆点/箭头切换，**主题联动跳系列筛选**（见 §6.2） |
| 品牌介绍 | 一句品牌主张 + 入口 | CTA 按钮跳转 `/about/company` |
| 精选产品 | 系列筛选 Tab（智能照明/智能安防/全屋智能）+ 产品卡片 | Tab 用 `data-active` 切换，`hf-btn` 风格 |
| 新闻动态 | 最新 3–4 条 | 跳转 `/news` |
| 预约 CTA | 大色块引导预约 | 跳转 `/about/appointment` |

### 4.4 产品模块
- **产品信息（/products）**：系列筛选（智能照明 `lighting` / 智能安防 `security` / 全屋智能 `whole`）+ 卡片网格。卡片含缩略图、名称、一句话卖点。
- **产品内容（/products/content）**：系列级介绍/解决方案长图文。
- **产品详情（/products/:id）**：图片画廊 + 规格 + **扩展属性（attrs，JSON 动态字段）** + 价格「面议」占位 + **搭配使用（related，JSON 关联推荐）**。
  > 扩展属性与搭配使用为动态结构，前端需支持遍历 `attrs` / `related` JSON，不硬编码字段。

### 4.5 新闻模块
- 列表支持「行业 / 产品」分类筛选；卡片含封面、标题、日期、摘要。
- 详情页：标题 + 元信息 + 正文（富文本渲染）+ 相关推荐。

### 4.6 招聘模块
- 列表支持「社会招聘 / 校园招聘」筛选。
- 职位详情：职责、要求、地点；投递方式为 **`mailto:` 邮箱投递**（原型实现），不使用在线表单，降低合规复杂度。

### 4.7 关于模块
- **品牌介绍**：企业简介 + 价值主张。
- **发展历程**：**水平时间轴**（`.tl-h-wrap/.tl-h-axis/.tl-h-grid/.tl-h-node/.tl-h-year`），年份用 Playfair 金色大字，节点可点击展开事件。
- **品牌历程**：品牌故事长图文。
- **在线预约（/about/appointment）**：预约表单（见 §6.4）。

### 4.8 联系我们（view-contact）
- 左：联系信息（地址/电话/邮箱/营业时间）+ 地图嵌入位（【待确认】地图服务商）；
- 右：留言表单（姓名/邮箱/留言内容 + 隐私提示）。

### 4.9 页脚（footer）
- 多列导航（产品/新闻/关于/联系）+ 版权 + 备案号占位（【待确认】）+ 社交图标。
- 背景 `ink.deep`，文字 `gold`/浅色，保持高端收尾。

## 第 5 章 后台管理系统设计规范

### 5.1 信息架构（IA）
```
登录 /login
工作台 /dashboard
内容管理
  ├ 轮播图管理   ★（首页 Banner 数据源）
  ├ 产品系列     （lighting/security/whole）
  ├ 产品管理
  ├ 新闻管理
  ├ 招聘管理
  └ 关于管理     （8 个 tab）
预约/留言管理
  ├ 预约管理
  └ 留言管理
系统管理
  ├ 管理员管理
  ├ 角色管理     （RBAC）
  └ 操作日志
数据统计
系统设置
```

### 5.2 整体布局（Ant Design 风格）
- **侧边栏**：宽 220px，底色纯黑 `menu(#000)`；菜单项 hover/激活为黑底金字（`menu-item`：`background:#000; color:#B98A2F`）。
- **顶栏**：高 56px，白底；含面包屑、用户信息、退出。
- **内容区**：底色 `layout(#FAF8F4)`，卡片白底 + `antd` 灰边框。
- **面包屑**：顶栏下方，标识当前路径。

### 5.3 登录页（view-login）
- 品牌色居中登录卡：账号 + 密码 + 登录按钮。
- **强制改密（L-04）**：首次登录/密码过期时，强制跳转改密流程（`forcePwd` 逻辑）。

### 5.4 工作台（view-dashboard）
- 顶部 4 张统计卡（`stat-card`）：预约数 / 留言数 / 产品数 / 新闻数。
- 7 天访问 PV **SVG 折线图**（纯 SVG，无图表库依赖，轻量）。
- 快捷入口（`quick`）：跳转高频管理页。

### 5.5 内容管理
- **轮播图管理（★）**：列表/表单维护 Banner（图片、标题、链接、排序）；链接可填 `/`、`/products?series=lighting` 等，直接驱动前台主题联动。
- **产品系列 / 产品 / 新闻 / 招聘**：标准 `ant-table` + 增删改查（`btn-primary` 新增、`btn-default` 编辑、`btn-danger` 删除带二次确认）。
- **关于管理**：8 个 tab 承载关于页各区块内容。
- **图片上传**：`upload` 组件（缩略图 + 进度）。

### 5.6 预约 / 留言管理
- 列表展示；**手机号脱敏显示**（`displayPhone`，如 138****8888）—— 隐私合规要求。
- 状态流转：`changeApptStatus` / `changeMsgStatus`（待处理→已处理），Drawer 查看详情。

### 5.7 系统管理
- **管理员管理**：账号、状态。
- **角色管理（RBAC）**：3 个内置角色 `super_admin` / `content_editor` / `operator`，按权限码（perms code）控制菜单与按钮可见性。
- **操作日志**：`view-log` 记录操作人/时间/动作。

### 5.8 数据统计（view-stats）
- 访问 PV 折线图、Top10 页面、预约来源饼图、留言条形图（均 SVG / 轻量实现）。

### 5.9 系统设置（view-settings）
- 轮播默认间隔（`sliderInterval`，默认 4s，驱动前台自动播放）、基础站点信息。
- 表单项：`lbl` + `inp` + `req`（必填红星）。

## 第 6 章 交互设计规范

### 6.1 导航与下拉（单例）
- 同一时刻仅一个下拉展开（G-02）；点击导航其他项、页面空白区、或已有下拉时关闭前一个。
- 键盘可达：Tab 聚焦、Enter/Space 展开、Esc 关闭，焦点管理不丢失。

### 6.2 轮播主题联动【原型已落地 · PRD §5.3.1】
- Banner 每张可配置 `link`；当 `link` 指向 `/products?series=xxx` 时，点击「查看产品」按钮跳转产品列表并**自动激活对应系列筛选**。
- 轮播间隔由后台 `settings.sliderInterval` 控制（运行时从 `STORE` 读取，默认 4s，最小 3s 保护）。
- 自动播放需支持 `prefers-reduced-motion` 降级为手动（见 §8）。

### 6.3 水平时间轴【原型已落地 · PRD §5.3.5】
- 结构：`tl-h-wrap`（容器）→ `tl-h-axis`（横轴）→ `tl-h-grid`（年份网格）→ `tl-h-node`（节点）→ `tl-h-year`（年份，Playfair 金色）。
- 节点可点击展开事件详情；移动端降级为竖向时间轴（见 §7）。

### 6.4 表单规范
- 统一 `lbl`（标签）+ `inp`（输入）+ `req`（必填红 `*`）。
- **预约表单字段**（前台）：姓名、手机号、预约类型、期望日期、时段、备注、**图形验证码** + **隐私提示文案**（勾选/说明）。
- **留言表单字段**（前台）：姓名、邮箱、内容 + 隐私提示。
- 校验：前端即时校验（手机号正则、必填），错误态 `inp` 红边 + 下方红字提示。
- 提交后 `toast` 成功反馈；失败给出明确错误。

### 6.5 弹窗 / 抽屉 / Toast / 二次确认（后台）
| 组件 | 样式 | 用途 |
|------|------|------|
| Modal | 右侧滑入，宽 560px | 表单编辑（新增/修改） |
| Drawer | 右侧滑入 | 预约/留言详情查看 |
| Toast | 顶部轻提示，z-60 | 操作成功/失败 |
| ConfirmDialog | 居中二次确认 | 删除等危险操作（S-05 二次确认约束） |

### 6.6 骨架屏（Skeleton）
- 列表/详情加载时使用 shimmer 骨架占位，避免布局跳动；数据到达后淡入替换。

### 6.7 图片灯箱（Lightbox）
- 产品详情/新闻封面点击放大查看；支持 Esc 关闭、遮罩点击关闭、左右切换。

## 第 7 章 响应式设计规范

### 7.1 断点
| 断点 | 区间 | 策略 |
|------|------|------|
| 桌面 | ≥1200px | 完整导航 + 12 列栅格 |
| 平板 | 768–1199px | 收起部分导航、栅格 8 列、卡片 2 列 |
| 移动 | <768px | 抽屉导航、单列堆叠、栅格 4 列/单列 |

### 7.2 前台响应式要点
- 导航：<768px 收起为 **汉堡按钮 → 移动抽屉**（`#drawer` + `#mask`）。
- 下拉：移动端改为抽屉内折叠展开，仍为单例。
- 产品/新闻卡片：桌面 3 列 → 平板 2 列 → 移动 1 列。
- 水平时间轴：移动端降级为竖向时间轴（保留年份金色大字）。
- Banner：移动端缩小字号、隐藏副文案，保持首屏一屏可见。

### 7.3 后台响应式策略【建议】
- 后台原型为固定桌面布局（侧栏 220 + 内容）；**建议** <1024px 时侧栏改为可收起抽屉，表格横向滚动；<768px 提供关键操作（审核/状态变更）的移动友好视图。
- 管理端以桌面为主，移动端为「可读可批处理」降级，不作完整重排版。

## 第 8 章 动效设计规范

### 8.1 通用原则
- **时长**：微交互 150–300ms；页面/视图进场 300–500ms。
- **属性**：仅用 `transform`（位移/缩放）与 `opacity`，避免触发重排（layout/paint），保证 60fps。
- **缓动**：`ease` / `cubic-bezier(.4,0,.2,1)`（标准 Material 缓动）。

### 8.2 常用动效
| 动效 | 实现 | 触发 |
|------|------|------|
| `fadeUp` | opacity 0→1 + translateY(12px→0) | 视图/区块进场 |
| 导航下划线 | width 0→100% | hover/active |
| 卡片悬浮 | `shadow-gold` + 轻微 translateY(-2px) | hover |
| 抽屉滑入 | translateX(-100%→0) | 打开导航/详情 |
| Banner 切换 | opacity 交叉淡入 | 轮播 |

### 8.3 无障碍降级（必须）
- 全局遵守 `prefers-reduced-motion: reduce`：关闭自动轮播、关闭位移类动效，仅保留必要淡入或直显。
- 轮播在 reduced-motion 下改为静态首图 + 手动切换。

## 第 9 章 无障碍与合规规范

> 本章吸收了 ui-ux-pro-max CLI 的通用最佳实践（WCAG 2.1 AA 优先），并对照原型已落地项固化。

### 9.1 对比度（P1 Accessibility · contrast-ratio）
- 正文文字与背景对比度 ≥ **4.5:1**；大号文字（≥24px 或 19px 粗体）≥ 3:1。
- 见 §3.1.1 安全组合表；浅底金字需加粗或改用 `gold.dark`。

### 9.2 焦点可见（P1 · focus-visible）
- 所有可交互元素（按钮、链接、节点、输入框）`:focus-visible` 显示 **2px 金色描边 + 2px offset**（原型 `.sf-btn/.hf-btn/.tl-h-node:focus-visible` 已落地）。
- 不以 `outline:none` 清除焦点，键盘用户必须有可见焦点。

### 9.3 触控目标（P2 Touch & Interaction · touch-target-size）
- 移动端可点击元素最小 **44×44px** 热区（图标可视觉 20px，但点击区放大到 44）。

### 9.4 语义与 ARIA
- 导航、菜单、轮播、抽屉、灯箱均提供 `aria-label` / `role`；
- 表单 `<input>` 必须关联 `<label>`（`lbl` + `inp` id 对应）；
- 轮播圆点提供 `aria-label="第 N 张"`；
- 抽屉/弹窗打开时聚焦首个可交互元素，关闭后焦点归还触发元素。

### 9.5 隐私与合规（个人信息保护法）
- 预约/留言收集手机号、邮箱等个人信息，必须：
  - 显示**隐私提示文案**并获用户明示同意（前台表单已落地隐私提示）；
  - 后台展示手机号**脱敏**（`displayPhone`）；
  - 日志不记录明文敏感信息；
  - 【建议】提供隐私政策页链接（【待确认】法务文案）。
